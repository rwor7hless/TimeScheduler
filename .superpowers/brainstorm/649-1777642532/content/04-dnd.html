Drag-and-drop, создание, удаление

Что можно делать в новом сайдбаре. Кликни галочкой пункты, которые НЕ нужны (multi-select). По умолчанию беру всё — это базовый набор того, что обычно ожидаешь от такого сайдбара.

Сценарий: тащим список «Соси» из «Без названия» в «Веселo»

Задачи
☀️Мой день
📋Задачи
Списки
▼ Веселo
📁[существующий список]
↳ бросить сюда
▼ Без названия
📁Соси ← drag
📁Шпрот
+ Список + Группа

Что поддерживаем (по умолчанию всё):

1

Тащить список из одной группы в другую

Drag handle на наведении / drag за всю строку. Drop-zone подсвечивается зелёным.

2

Выбросить список из группы (на верхний уровень)

Drag в зону между группами или в самый низ секции «Списки».

3

Переставлять списки внутри группы

Сортировка сохраняется на бэке (sort_order у Board).

4

Переставлять группы между собой

Drag за заголовок группы. Sort_order у Group.

5

Тащить задачу из «Задачи»/«Мой день» в список (board)

Сейчас этого нет вообще. Это уже сложнее — нужны DnD-сенсоры на двух разных компонентах. Можно отложить.

Создание / удаление / переименование

A

+ Список → модалка с именем и селектом группы

Опционально можно выбрать группу при создании. Без группы = верхний уровень.

B

+ Группа → инлайн-инпут «Введи имя группы»

Без модалки. Esc отменяет, Enter создаёт. Группа без имени запрещена (или дефолт «Новая группа»).

C

Переименование — двойной клик или меню «...»

Инлайн-инпут прямо в сайдбаре. Esc отменяет.

D

Удаление группы → модалка «Куда деть списки?»

Радио: «Перенести на верхний уровень» (дефолт) / «Удалить вместе со списками и задачами». Без подтверждения нельзя.

E

Удаление списка — как сейчас

Модалка с конфирмом. Задачи переезжают в no-list (board_id=null) → видны в «Задачи».

Кликни то, что НЕ нужно (или ничего, если всё ОК). По умолчанию беру весь список 1-4 + A-E. Пункт 5 (drag задачи в список) предлагаю отложить — он open большой банки червей.
